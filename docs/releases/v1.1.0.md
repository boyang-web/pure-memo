# 纯粹备忘录 v1.1.0

> 打开就写，退出即存的极简卡片备忘录。零后端、纯前端，数据只留在本机。

这个版本把「记一条」的路径又缩短了一截：编辑从居中弹层搬到看板顶部，卡片可以按住拖动排序、拖进置顶组就算置顶；同时把整套拖拽动画重做了一遍。

## 本次更新

### 新增

- **拖拽排序**：按住卡片约 0.3 秒即可拖起来换序，靠近上下边缘会自动滚动。
- **拖进「置顶」即置顶**：拖进置顶分区就置顶，从置顶分区往下拖出来即取消置顶，拖动过程中实时预览置顶状态。
- **顶部整行编辑大卡**：点任意卡片，直接在置顶分组上方展开一张整行大卡片改写，取消不改动原文。

### 改进

- **拖拽手感**：被按住的卡片会浮起（放大、加深阴影），跟随手指时带一点延迟与速度倾斜，其余卡片带着加减速让位；松手后卡片收拢落回格子。
- **动画不卡了**：落点判定改用几何缓存，`pointermove` 合并进 `requestAnimationFrame`；换序动画从 23 帧关键帧压到 2 帧，同一次换序共用一个时长；拖拽期间临时关掉卡片毛玻璃、冻结背景光斑。实测 60 次连续换序下稳定 60fps 以上、没有超过 32ms 的长帧。
- **重绘更省**：`render()` 改为复用已有卡片节点，只移动和增删变化的部分，不再整板重建。

### 修复

- 拖拽换序时卡片完全没有动画（`cardIn` 的 `animation-fill-mode: both` 压掉了脚本动画）。
- 换序动画被打断时会先跳回格子位置再重新出发，现在从当前位置接着走。
- 单列视图下拖拽落点判定错误：手指在左半边时卡片往下只能挪一格就卡住，在右半边又会整格跳过头。
- 松手后卡片落位偏慢（固定 230ms 改为按距离自适应 110–200ms）。
- 把卡片移出置顶后，空的「置顶」分组标题会残留。

### 变更

- 移除顶栏「排序」按钮：顺序只由拖拽决定。卡片数据新增 `order` 字段，旧数据首次读取时按创建时间自动补齐，**不需要手动迁移**。
- 移除长按唤出菜单；卡片操作统一走右上角 ⋯，菜单里也去掉了「编辑」（点卡片即编辑）。

## 下载与安装

| 方式 | 适合 | 说明 |
| --- | --- | --- |
| `PureMemo-v1.1.0-web.zip` | 自建部署 | 解压后放到任意静态服务器（需 HTTPS 或 localhost）即可；也可直接上传到 GitHub Pages / Netlify 等。 |
| 源码 zip / tar.gz | 查看与二次开发 | GitHub 自动生成，内容与标签一致。 |
| Android APK | 直接装机 | **本次未重建**，`release/PureMemo-v1.0.apk` 仍是 v1.0 的 WebView 壳；v1.1 的新交互请用网页版。 |

Web 版在手机上打开后，用浏览器的「添加到主屏幕 / 安装应用」即可获得接近原生的独立窗口与离线能力。

## 校验

`SHA256SUMS.txt` 随发布包提供，下载后可核对：

```bash
shasum -a 256 -c SHA256SUMS.txt     # macOS
sha256sum -c SHA256SUMS.txt         # Linux
```

## 升级提示

- 数据全部存放在浏览器 `localStorage`，升级不会清除已有内容；新版本首次读取旧数据时会自动补齐 `order` 字段。
- 已安装到主屏幕的用户：打开一次即可通过 Service Worker 拿到新版本（缓存版本已升至 `purememo-v9`）；若界面没变化，关掉再重开一次。
- 仍然没有导出 / 导入功能，清除站点数据或卸载 App 会丢失全部内容，请不要把这里当作重要内容的唯一备份。
