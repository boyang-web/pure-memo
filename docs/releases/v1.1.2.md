# 纯粹备忘录 v1.1.2

> 打开就写，退出即存的极简卡片备忘录。零后端、纯前端，数据只留在本机。

这个版本只修一件事：**v1.1.1 的 APK 装不上**。如果你在手机上看到「不兼容」「应用未安装」或「解析包时出现问题」，下载本版重装即可。

## 问题原因

`targetSdk` 定为 34（≥ 30），Android 11 起对这种包有一条硬性要求：`resources.arsc` 必须**未压缩存放且 4 字节对齐**，否则系统无法把它映射进内存，安装器直接判为无效包。

v1.1.1 的打包脚本在最后一步用 Python `zipfile` 重打包时，默认把每个条目都 Deflate 压缩了，`resources.arsc` 也没幸免。`zipalign -c` 对「被压缩的文件」不会报警，所以当时的校验没发现。桌面上的静态检查、签名校验全过，一到手机安装就失败。

## 修复

- `resources.arsc` 与 `classes.dex` 改为 STORED（不压缩）写入，再由 `zipalign -p 4` 对齐；实测 `resources.arsc` 偏移 `106220`，可被 4 整除。
- `scripts/build_apk.py` 打包后显式校验压缩方式与数据偏移，不对就直接失败。
- 新增 `scripts/check_apk.py`：只读 APK 的 zip 结构，不需要 Android SDK，CI 里也会跑。以后再出现同类打包错误，推送时就会被拦下，而不是等用户装不上。
- Service Worker 缓存升至 `purememo-v11`。

## 下载与安装

| 文件 | 说明 |
| --- | --- |
| `PureMemo-v1.1.2.apk` | Android 安装包（121 KB，versionCode 10102） |
| `PureMemo-v1.1.2-web.zip` | 静态站点，解压部署 |
| `SHA256SUMS-v1.1.2.txt` / `SHA256SUMS.txt` | 校验和 |

v1.1.2 与 v1.1.1 **同一把签名密钥**；如果 v1.1.1 曾经装上过，可以直接覆盖安装，数据保留。更早的 v1.0 用的是另一把密钥，装过它仍需先卸载。

APK 的最低系统版本是 Android 7.0（API 24）。如果你的手机系统更老，或者装了这一版仍然提示不兼容，请把**手机型号、Android 版本、安装器显示的完整提示、下载后 APK 的文件大小**告诉我，我再针对性处理。

## 校验

```bash
shasum -a 256 -c SHA256SUMS-v1.1.2.txt     # macOS
sha256sum -c SHA256SUMS-v1.1.2.txt         # Linux
```
