# 纯粹备忘录 v1.1.1

> 打开就写，退出即存的极简卡片备忘录。零后端、纯前端，数据只留在本机。

这个版本补上了 v1.1.0 留下的缺口：**Android 安装包**。v1.0 之后再没重建过 APK，网页版的新交互一直只存在于浏览器里；这次把壳工程源码放回仓库，用脚本重新构建，APK 与网页版终于是同一份代码。

## 本次更新

### Android APK（重点）

- **重新构建**：`PureMemo-v1.1.1.apk`（113 KB，最低 Android 7.0）。内含 v1.1 的全部改动——顶部整行编辑大卡、拖拽排序、拖进置顶组即置顶、动画重做。
- **完全离线**：页面与图标都打进 `assets/`，启动不发起任何网络请求，断网、飞行模式下照常打开。
- **数据留在 App 内**：壳把本地资源映射成 `https://appassets.androidplatform.net/`，给出稳定 origin，`localStorage` 行为与浏览器一致；卸载 App 才会清空。
- **状态栏跟随主题**：页面切深浅主题时，状态栏与导航栏底色、图标明暗一起变，不留色块。
- **切后台自动落稿**：壳在暂停时派发 `pagehide`，正在写的草稿不会因为切走而丢。

### 仓库补全

- `android/` 壳工程源码入库（此前只有成品 APK，源码缺失）。
- `scripts/build_apk.py`：一条命令出签名包，不依赖 Gradle，只要 JDK 17 与 Android SDK。版本号从 `index.html` 的 `app-version` 读，`versionCode` 自动算，未签名包时间戳固定，**同一份源码两次构建字节一致**。
- `docs/DEVELOPMENT.md` 补上壳的实现细节与构建链路；`docs/RELEASING.md` 补上 APK 的发版步骤。

## 下载与安装

| 文件 | 适合 | 说明 |
| --- | --- | --- |
| `PureMemo-v1.1.1.apk` | 直接装机 | 下载后允许「安装未知来源应用」即可安装。 |
| `PureMemo-v1.1.1-web.zip` | 自建部署 | 解压后放到任意静态服务器（需 HTTPS 或 localhost）；也可直接上传到 GitHub Pages / Netlify。 |
| `SHA256SUMS-v1.1.1.txt` | 校验 | APK 的 SHA-256。 |

iOS、或想免安装的话，仍可直接用网页版「添加到主屏幕」，功能一致。

## 升级提示

- **已装 v1.0 APK 的必须先卸载**：v1.0 的签名私钥没有入库，新包签名不同，Android 会拒绝覆盖安装。卸载会清空 App 内的数据，如有需要请先把内容复制到别处。
- 首次安装后数据为空，属于正常现象（v1.0 的数据在旧包内，无法迁移）。
- 网页版升级不受影响：打开一次即可通过 Service Worker 拿到新版本（缓存已升至 `purememo-v10`），界面没变化就关掉重开一次。
- 依然没有导出 / 导入功能，清除站点数据或卸载 App 会丢失全部内容，请不要把它当作重要内容的唯一备份。
